# 全项目缺陷与性能审计（P11）

## 范围与方法

本轮按认证/租户、设备/证书、遥测/告警、固件/命令、HA/存储、前端、Agent 七个域审阅，
每条缺陷先复现再修，修复带回归用例。性能部分先取基线，只保留有前后数据的改动。

## 已修复

| 级别 | 缺陷 | 修复 |
|---|---|---|
| Critical | 生产新库带 `admin/admin123` 默认管理员 | 启动期校验默认口令；生产未提供 `EDGEPULSE_ADMIN_PASSWORD` 时拒绝启动，提供则 CAS 更新；开发档保留默认口令 |
| Important | Redis 半开连接时同步 PUBLISH 可阻塞事件循环 30s | 发布连接查询超时收紧到 2s；本地投递优先，远端事件在故障期为尽力而为 |
| Important | 并发续期/慢事件循环下租约本地截止可能晚于数据库到期 | 租约截止锚定在授权时刻，续约带 `expires_at > now`，清理带 fence |
| Important | 固件灰度 `listDue` 固定 LIMIT 20 可饥饿 | 候选窗口提升到 100 并按主键游标轮转 |
| Important | 命令卡在 pending/running 无收敛 | leader 按 `deadline_at` 索引扫描超时命令，事务内置 timeout 并结束绑定固件任务；迟到结果被终态保护 |
| Important | 固件删除在事件循环同步删文件 | 文件删除移入阻塞执行器，失败只记日志 |
| Important | 迟到的 `failed` 固件状态可覆盖 `installed` | 失败更新加终态保护；终态重复回报不再改写 |
| Important | 灰度中止/提升不能中断已运行安装 | 明确为“停止后续派发 + 服务端记账”，UI/文档同步；迟到终态不覆盖 canceled/failed |
| Minor | MFA 恢复码、验证码/OIDC 一次性消费、API Token 委派、证书重叠、灰度表单等 | 见各阶段 ledger 的已修条目 |

## 明确延期（非本轮阻塞）

- 命令超时扫描的 30s 粒度与 30s grace 为常量；升级前已进入 running 且
  `deadline_at` 为空的行不补扫。
- 灰度波次/目标写入与发布头 CAS 仍非同一事务；崩溃后可能出现目标领先于波次，
  已用每拍重读、状态幂等与终态保护降低影响。
- 灰度 `listDue` 仍是固定窗口（100），不是全量公平队列。
- 旧 Agent 不上报 `installed_firmware_version` 时，默认 `requireInstalledVersion`
  会让灰度等满观测窗口后失败；升级前需确认 Agent 版本。
- 租户停用只阻断续期，不阻断既有 Agent 数据面；通用事件订阅、CSV 导入、
  多地域多活、对象存储固件不在本轮。
- MySQL 真机外部用例、systemd 真机、HA 备份恢复演练由 P12/CI 覆盖，本地
  SQLite 通过不等于 MySQL 通过。
