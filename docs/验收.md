# EdgePulse P0 验收

- 日期：2026-10-20
- 环境：Windows 10.0.26300 / MSVC 14.51 / CMake 4.2.3 / Conan 2.25.1 / Node 24 / Edge 系统浏览器
- 结论：P0 通过（后端 35/35、前端单测 22/22、前端构建通过、Playwright 1/1、协议验收 17/17）

## 1. 复现命令

```bash
# 后端
conan install . --build=missing -s compiler.cppstd=23 -s build_type=Release
cmake --preset debug
cmake --build --preset debug
ctest --preset debug --output-on-failure

# 前端
cd frontend
npm ci
npm run test:unit
npm run build
npm run test:e2e

# 协议与安全
cd ..
python scripts/check-acceptance.py
```

`check-acceptance.py` 在服务未启动时会用 `scripts/run-dev.sh` 启动，并在结束时停止自己启动的进程。

- 迁移切分、幂等应用、校验和拒绝、种子与仓储读取
- PBKDF2 种子/新哈希/畸形输入、验证码一次性/过期/IP 限流、会话滑动/登出
- 认证服务登录/错误验证码/错误口令/改密，HTTP 认证端点
- 节点 CRUD、乐观锁冲突、Agent 指纹拒绝、状态发布、HTTP 权限矩阵
- 健康检查与统一响应包络

### 2.2 前端

- `npm run test:unit`：22 条通过（包含新增的节点 API 契约测试）
- `npm run build`：`vue-tsc --noEmit` 与 `vite build` 通过
- `npm run test:e2e`：1 条通过——管理员登录、进入 `/device/nodes`、WebSocket 首条认证完成（`data-ws-state="connected"`）

### 2.3 协议与安全

`python scripts/check-acceptance.py` 实测输出：

```text
PASS 8080 验证码签发：HTTP 200
PASS 管理员登录：HTTP 200
PASS 响应回写 x-request-id：0004-0000000000000005
PASS me 返回角色与权限：HTTP 200
PASS routes 返回节点菜单：device/Nodes
PASS 8443 HTTPS 健康检查：HTTP 200
PASS TCP 侧不存在 h3 专属路径：HTTP 404
PASS H3Probe 真实 h3：status=200 body={"code":200,"data":{"proto":"h3"},"message":"ok",...}
PASS 9443 无客户端证书被拒
PASS 9443 正确证书注册并心跳：nodeId=… heartbeats=3
PASS 9443 正确证书走 HTTP 注册：HTTP 200
PASS 节点列表可读：HTTP 200
PASS Agent 注册的节点出现在列表：edgepulse-agent-http, edgepulse-agent
PASS 浏览器 WebSocket 首条认证：ws-auth-ok

PASS 9100 /metrics 带令牌可读：HTTP 200
PASS 9100 /healthz：HTTP 200
P0 验收全部通过
```

h3 的判据是“h3 专属路径返回 200”；同一路径走 TCP 是 404，因此 TCP 回落不会被误判为 h3。

mTLS 的判据是“无客户端证书握手失败、正确证书注册并心跳成功”；指纹白名单在注册时按 Agent 自报值校验（见架构文档的边界说明）。

## 3. 已知偏差与未覆盖

| 项目 | 状态 | 说明 |
|---|---|---|
| WebSocket 5 秒认证兜底 | 已实现，非最终形态 | 引擎 `receive()` 无超时；当前用计时线程，实现里标了 `shortcut` |
| 生产静态 SPA | 未启用 | P0 浏览器入口是 Vite 5173；后端静态托管在 P3 前补齐 |
| MySQL/Redis 运行时 | 未启用 | P0 开发档 SQLite + 进程内会话；MySQL/Redis 集成测试按 P1 |
| mTLS 指纹逐请求绑定 | 应用层近似 | 处理器读不到证书；TTL 层用 CA/客户端证书，注册层用自报指纹白名单 |
| SSE、Agent WS、遥测、告警、固件、命令 | 未实现 | P2 |
| 多 worker、零停机、OTLP、容器/systemd | 未验收 | P3；现有样例不声称已验收 |
| 性能基线 | 未记录 | 按提示词要求不拍阈值；P3 再建基线 |
| 错误指纹拒绝（TLS 层） | 未单独测 | 白名单在注册层；TLS 层是 CA 链 + 客户端证书必需 |
