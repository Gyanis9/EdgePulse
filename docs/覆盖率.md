# EdgePulse 覆盖率（P0）

不写覆盖率百分比；按“场景 × 状态 × 验证方式”列出 P0 覆盖的证据与缺口。

## 1. 后端（GoogleTest，35 条）

| 场景 | 状态/分支 | 验证 |
|---|---|---|
| 迁移文件切分 | 引号内分号、行注释、块注释、未闭合 | `MigrationSqlSplitter.*`（4 条） |
| 迁移应用 | 首次、二次幂等、校验和篡改 | `Migrations.AppliesSchemaSeedAndIsIdempotent`、`Migrations.RejectsChecksumMismatch` |
| 种子仓储 | 用户、角色、权限、菜单树 | `Migrations.RepositoriesReadSeedData` |
| 分页 | 默认、上限、非法值、载荷字段 | `Pagination.*`（4 条） |
| 时间格式 | RFC 3339 形状、纪元零点 | `TimeFormat.*`（2 条） |
| 口令哈希 | 种子校验、错误口令、格式、畸形 | `PasswordHash.*`（3 条） |
| 验证码 | 一次性、大小写、TTL、IP 限流 | `CaptchaService.*`（3 条） |
| 会话 | 滑动过期、登出、未知令牌 | `SessionStore.*`（2 条） |
| 认证服务 | 登录、错误验证码/口令、改密后旧口令失效 | `AuthService.*`（3 条） |
| 认证 HTTP | 验证码→登录→me→routes→登出、匿名 401 | `AuthEndpointsTest.*`（4 条） |
| 节点服务 | 创建/分页/乐观锁/删除 | `DeviceService.CreatesListsUpdatesAndRemovesNode` |
| Agent | 指纹拒绝、注册、心跳、发布计数 | `DeviceService.AgentRegistrationChecksFingerprintAndPublishesStatus` |
| 节点 HTTP | CRUD、匿名 401、只有列表权限 403 | `NodeEndpointsTest.*`（2 条） |
| 响应包络 | 成功/失败字段、data null | `ApiResponse.SuccessAndFailureShareEnvelopeShape` |
| 健康检查 | 200 包络、未知路径 JSON 404 | `HealthServer.*`（2 条） |

## 2. 前端（node:test，22 条）

| 场景 | 验证 |
|---|---|
| HTTP 契约 | bearer、查询串、包络解包、403 ApiError、401 清理 |
| 认证 API | captcha/login/me/routes/password/logout 路径与请求体 |
| 系统/门户 API | 用户/角色/菜单/部门/岗位/字典/配置/日志与 dashboard/health |
| 节点 API | 列表分页与过滤、创建、更新、删除 |
| 工具函数 | 校验、CSV 转义、剪贴板、权限图、问句匹配、热力图、配置推断 |

## 3. 端到端（Playwright，1 条）

`frontend/e2e/login-nodes.spec.ts`：Edge 实例登录 → `/device/nodes` → 标题/列表可见 → WebSocket 认证状态 `connected`。

## 4. 协议与安全验收（check-acceptance.py，17 项）

验证码、登录、trace id、me、routes、8443 HTTPS、TCP h3 404、H3Probe 真实 h3、mTLS 无证书拒绝、正确证书注册+心跳、节点列表包含 Agent、WebSocket 首条认证、metrics 401/200、healthz。

## 5. 缺口（按阶段）

| 缺口 | 阶段 |
|---|---|
| 低权限账号真实登录后的 403 矩阵、数据范围 SQL | P1 |
| MySQL/Redis 真实集成测试（环境变量门控） | P1 |
| WebSocket 首条认证 5 秒超时的自动化用例 | P2（当前实现为 `shortcut` 计时线程） |
| 错误指纹/每节点证书绑定 | P2 |
| SSE 心跳/断线重连、Agent WebSocket、告警 2 秒到达 | P2 |
| 100 MiB 固件上传下载与 Range/ETag | P2 |
| 多 worker、零停机、OTLP、容器/systemd | P3 |
| SPA 后端静态托管与深链回退 | P3 前 |
| 性能基线 | P3（不设拍脑袋阈值） |
