# EdgePulse 覆盖率

覆盖率按“被测试钉住的行为”统计，不引用未实际运行的覆盖率工具数字。

## 1. 后端

`ctest --preset debug` 共 55 条用例：

| 目标 | 条数 | 覆盖内容 |
|---|---:|---|
| 单元 | 22 | 验证码一次性/过期/限流、CSV BOM 与转义、内存 KV、迁移切分器、分页、密码、会话滑动、时间格式 |
| 集成 | 16 | 迁移 V1–V6 与幂等/校验和、种子仓储、认证与审计、用户 CRUD、数据范围、角色菜单、字典参数、遥测最新/序列、告警触发恢复、命令生命周期、固件任务、节点分组 |
| 协议 | 17 | 认证 401/403、用户/角色/菜单/部门/岗位/字典/参数、导出、审计、遥测告警、命令往返、固件上传/Range/ETag/下发、节点分组、节点 CRUD、WebSocket 首条认证、健康 404 |

未覆盖或只做静态检查：

- MySQL/Redis 真机驱动路径（需要 `EDGEPULSE_TEST_MYSQL_*` / `EDGEPULSE_TEST_REDIS_*`）。
- OTLP 采集端真实送达。
- Docker 镜像构建与 systemd 真机启动。
- 多进程 worker 编排与跨进程实时扇出。

## 2. 前端

`npm run test:unit` 共 23 条：

- API 契约：HTTP 客户端、认证、会话、系统管理、设备、门户、fleet（节点分组/遥测/告警/命令/固件/运维）。
- 工具：权限分析、问答意图、登录热力、配置项推断、表单校验。
- 设备推送：nodeSocket 的首条认证、主题消息分发与清理逻辑由 Playwright 的 WebSocket 连接与页面用例共同覆盖。

`npm run test:e2e` 共 3 条：

- 管理员登录 → 节点页 → WebSocket `connected`。
- 系统用户页加载。
- 告警、遥测、固件、命令四个设备页渲染。

## 3. 协议与安全

`scripts/check-acceptance.py` 覆盖认证、系统管理、节点、遥测告警、SSE、命令、100 MiB 固件、h3、mTLS、metrics、readyz。每项独立打印 PASS/FAIL，失败即非零退出。

## 4. 未覆盖风险

- 真实边缘网络的丢包、NAT、证书轮换与 Agent 长时间断线重连。
- 高并发下的连接池饱和、限流桶、内存预算与 WebSocket 背压。
- 生产 MySQL 的 DDL 隐式提交与跨版本差异。
- 浏览器兼容性只验证了系统 Edge。
