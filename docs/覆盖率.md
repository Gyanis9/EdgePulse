`scripts/check-docker-stack.py` 覆盖镜像构建、MySQL/Redis、登录与业务写入、会话跨重启、Prometheus 抓取、真实 OTel collector 与 SIGTERM 优雅停机。

## 4. 未覆盖风险

- 真实边缘网络的丢包、NAT、证书轮换与 Agent 长时间断线重连。
- 高并发下的连接池饱和、限流桶、内存预算与 WebSocket 背压。
- 生产 MySQL 的跨版本差异与 DDL 隐式提交：本机只在 MySQL 8 容器验证。
- 多实例部署下离线扫描、保留期清理与指标刷新的重复执行；当前没有选主或分布式锁。
- 浏览器兼容性只验证了系统 Edge。
- Docker 镜像只在 x86_64 Linux 容器验证，多架构构建未覆盖；systemd 只在特权容器验证。
