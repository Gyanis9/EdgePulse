| 协议 | 19 | 认证 401/403、用户/角色/菜单/部门/岗位/字典/参数、导出、日志数据范围、审计、遥测告警、命令往返、Agent WebSocket 推送、固件上传/Range/ETag/下发、节点分组、节点 CRUD、WebSocket 首条认证、健康 404 |

未覆盖或只做静态检查：

- 多进程 worker 编排与跨进程实时扇出。

## 2. 前端

`npm run test:unit` 共 23 条：

- API 契约：HTTP 客户端、认证、会话、系统管理、设备、门户、fleet（节点分组/遥测/告警/命令/固件/运维）。
- 工具：权限分析、问答意图、登录热力、配置项推断、表单校验。
- 设备推送：nodeSocket 的首条认证、主题消息分发与清理逻辑由 Playwright 的 WebSocket 连接与页面用例共同覆盖。

`npm run test:e2e` 共 3 条：

- 管理员登录 → 节点页 → WebSocket `connected`。
- 系统用户页加载。
- 告警、遥测、固件、命令四个设备页渲染。

## 3. 协议与安全

`scripts/check-acceptance.py` 覆盖认证、系统管理、节点、遥测告警、SSE、命令、Agent WebSocket、OTLP mock、100 MiB 固件、h3、mTLS、metrics、readyz，共 50 项。每项独立打印 PASS/FAIL，失败即非零退出。

## 4. 未覆盖风险

- 真实边缘网络的丢包、NAT、证书轮换与 Agent 长时间断线重连。
- 高并发下的连接池饱和、限流桶、内存预算与 WebSocket 背压。
- 生产 MySQL 的跨版本差异与 DDL 隐式提交：本机只在 MySQL 8 容器验证。
- 浏览器兼容性只验证了系统 Edge。
