## 2. 前端

`npm run test:unit` 共 23 条：

- API 契约：HTTP 客户端、认证、会话、系统管理、设备、门户、fleet（节点分组/遥测/告警/命令/固件/运维）。
- 工具：权限分析、问答意图、登录热力、配置项推断、表单校验。
- 设备推送：nodeSocket 的首条认证、主题消息分发与清理逻辑由 Playwright 的 WebSocket 连接与页面用例共同覆盖。

`npm run test:e2e` 共 6 条：

- 管理员登录 → 节点页 → WebSocket `connected`。
- 系统用户页加载。
- 告警、遥测、固件、命令四个设备页渲染。
- 自定义数据范围选择部门、保存并回显。
- OIDC 企业登录按钮与一次性 code 换会话。
- 平台管理员创建租户，租户管理员按编码登录并只看到本租户账号。

## 3. 协议与安全

`scripts/check-acceptance.py` 覆盖认证、租户创建/登录隔离/停用与旧会话失效、租户级 RBAC、系统管理、通知 Webhook/邮件真实投递、节点、遥测告警、SSE、批量/计划命令、Agent WebSocket、OTLP mock、UDP 遥测、OIDC、100 MiB 固件、h3、mTLS、metrics、readyz，共 69 项。每项独立打印 PASS/FAIL，失败即非零退出。

`scripts/check-docker-stack.py` 覆盖镜像构建、MySQL/Redis、登录与业务写入、会话跨重启、Prometheus 抓取、真实 OTel collector 与 SIGTERM 优雅停机，共 21 项。

## 4. 未覆盖风险

- 真实边缘网络的丢包、NAT、证书轮换与 Agent 长时间断线重连。
- 高并发下的连接池饱和、限流桶、内存预算与 WebSocket 背压。
- 生产 MySQL 的跨版本差异与 DDL 隐式提交：本机只在 MySQL 8 容器验证。
- 浏览器兼容性只验证了系统 Edge。
- Docker 镜像只在 x86_64 Linux 容器验证，多架构构建未覆盖；systemd 只在特权容器验证。
