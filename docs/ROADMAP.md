# EdgePulse Roadmap

本文件列出已经明确延后、暂不进入默认交付范围的能力。每项都写了原因与前置依赖；没有这些依赖就实现，会把当前单实例、可解释的运维模型变得不可验证。

| 项目 | 延后原因 | 前置依赖 |
|---|---|---|
| API v1 / OpenAPI / 幂等键 | 当前 `/api` 未版本化，写操作没有幂等键；直接冻结会把现有客户端问题带进长期契约 | 契约盘点、OpenAPI 生成与校验、破坏性变更策略、客户端迁移计划 |
| OTLP tracing | 目前只有指标出口，缺 span 上下文传播、采样与 trace 与日志的关联 | 引擎侧追踪钩子、请求上下文透传、采集端与采样策略 |
| HA 选主 | 离线扫描、生命周期与保留期清理依赖进程内定时器，计划命令的到点判断在查询侧；多实例没有租约或活动实例协调 | MySQL/Redis 租约、故障切换语义、脑裂测试与运维手册 |
| MFA | 目前是口令 + OIDC，没有第二因素注册、恢复码与管理员重置流程 | TOTP/WebAuthn、恢复码、审计事件与租户策略 |
| 通用事件订阅 | 浏览器 WS 主题与告警 SSE 是固定集合，外部系统无法按 schema 订阅 | 事件 schema、订阅授权、投递保证与重放策略 |
| OTA 自动灰度与健康门控 | 固件批次目前手动推进，没有自动健康判断、暂停与回滚窗口 | 节点健康信号、观察窗口、自动回滚策略与演练 |
| CSV 导入与批量节点编辑 | 现在只有导出；批量写需要行级校验、dry-run 与部分失败报告 | 导入 schema、权限与数据范围边界、审计与回滚方案 |
| API Token | 管理端只有浏览器 Bearer 会话，没有面向自动化的长期凭据 | 作用域、租户绑定、轮换与吊销、审计与速率限制 |

这些项目不是缺陷清单。需要其中某一项时，先补前置依赖与验收口径，再单独设计；不要把未完成的能力写进 README 的已交付特性。
