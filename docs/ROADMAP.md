# EdgePulse Roadmap

本文件列出已经明确延后、暂不进入默认交付范围的能力。每项都写了原因与前置依赖；没有这些依赖就实现，会把当前控制面双实例、可解释的运维模型变得不可验证。

## 已交付（2026-10-26，P7–P10）

| 能力 | 交付范围 | 仍不在范围内 |
|---|---|---|
| API Token | `ep_api_` 明文只显示一次，只存 SHA-256 与前缀；scope 与 owner 当前权限取交集；按租户列出、轮换 1 小时重叠、吊销保留记录；权限码 `system:token:*` | 按令牌的独立速率限制、父令牌级联吊销、跨租户服务账号 |
| TOTP 两步验证 | RFC 6238 TOTP、AES-256-GCM 加密秘密、HMAC 恢复码、登录挑战与 5 次失败上限、会话态尝试上限、管理员重置、用户自助设置 | 租户级强制策略、WebAuthn、密钥轮换与 AAD 绑定 |
| 写请求幂等键 | `Idempotency-Key` 24 小时重放、内容/权限冲突 409、90 秒处理中租约、保留期清理、敏感路径整段排除 | 完整响应头白名单、业务级重复执行防护 |
| OpenAPI 3.1 | `/api/openapi.json`、源码路由与 notes 生成、CI 字节级 `--check`、P7 端点覆盖 | 运行时 schema 校验、严格规范校验器、`/api/v1` 前缀 |
| 控制面 HA | 双实例共享 MySQL/Redis/固件卷；`sys_lease` 租约与 fence 单飞、MySQL 迁移锁、跨实例 Agent 命令路由、五项依赖的 `/readyz`、Compose/nginx/systemd 编排与双实例验收 | 存储层高可用、跨地域多活、自动分片、租户/Agent 数据面限额 |
| 固件灰度发布 | 波次物化、命令/任务/已安装版本/心跳/遥测/告警六类健康判据、暂停/恢复/提升/强制提升/中止/回滚、自动回滚与确认、leader 单飞、管理端向导与详情；V22/V23 迁移 | A/B 分区、差分下载、分组目标、波次/目标写入与发布头同事务 |

这些能力已经进入默认运行形态，不再作为 Roadmap 的延后项；上表最后一列是后续可单独设计的缺口，不应被解读为已交付。

## 延后项

| 项目 | 延后原因 | 前置依赖 |
|---|---|---|
| `/api/v1` 版本前缀 | 当前 `/api` 直接承载契约；OpenAPI 已冻结现状，但还没有破坏性变更策略与客户端迁移计划 | 兼容性矩阵、弃用周期、客户端迁移与双栈路由 |
| OTLP tracing | 目前只有指标出口，缺 span 上下文传播、采样与 trace 与日志的关联 | 引擎侧追踪钩子、请求上下文透传、采集端与采样策略 |
| 存储层高可用与跨地域多活 | P9 的控制面双实例仍共享单点 MySQL/Redis，没有复制、自动故障转移、跨地域复制或自动分片；先把控制面租约与故障切换跑稳，再单独设计存储拓扑 | 托管或自建存储的复制方案、切主流程、跨地域延迟预算、脑裂与数据丢失窗口的验收口径 |
| 租户/Agent 数据面限额 | 当前只有按实例的全局限流，没有按租户配额、按 Agent 命令并发上限、固件下载带宽或按令牌限流 | 配额模型与计量、超限反馈与审计、网关层限流方案、热点租户隔离 |
| 租户级 MFA 强制策略 | 当前 MFA 是用户自助启用；强制上线需要先有恢复与豁免流程，否则可能把管理员锁在系统外 | 租户策略模型、豁免与恢复 runbook、登录审计与用户通知 |
| 通用事件订阅 | 浏览器 WS 主题与告警 SSE 是固定集合，外部系统无法按 schema 订阅 | 事件 schema、订阅授权、投递保证与重放策略 |
| 固件灰度的 A/B 与差分下载 | 当前回滚是重新下发历史固件，没有本地槽位或差分包；边缘带宽与回滚耗时受限 | Agent 侧双槽位与回滚引导、差分包格式与签名、失败恢复演练 |
| 固件灰度目标与调度扩展 | 只接受节点标识，没有分组目标；波次/目标写入与发布头 CAS 不在同一事务 | 分组展开与预览、单目标派发事务成本评估 |
| CSV 导入与批量节点编辑 | 现在只有导出；批量写需要行级校验、dry-run 与部分失败报告 | 导入 schema、权限与数据范围边界、审计与回滚方案 |

这些项目不是缺陷清单。需要其中某一项时，先补前置依赖与验收口径，再单独设计；不要把未完成的能力写进 README 的已交付特性。
